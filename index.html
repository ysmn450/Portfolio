Ma formation

Le BTS SIO

Le BTS Services Informatiques aux Organisations (SIO) est une formation en deux ans qui prépare aux métiers de l'informatique en entreprise. Il répond aux besoins actuels des organisations en matière de développement, gestion des systèmes, réseaux et cybersécurité. Cette formation permet d'acquérir des compétences techniques solides ainsi qu'une capacité à travailler en équipe et en mode projet.

Deux spécialités sont proposées :

🌐

Option SISR

L'option SISR est axée sur la gestion des infrastructures informatiques. Elle prépare à installer, configurer et administrer des réseaux et des serveurs, tout en garantissant leur performance et leur sécurité.

💻

Option SLAM ← Ma voie

L'option SLAM est orientée vers le développement. Elle forme à la conception, au développement et à la maintenance d'applications web, mobiles ou logicielles.

🎯 Ma problématique : En quoi l'IA est-elle un outil d'aide au développement et quelles sont ses limites ?

Thème 1 — C'est quoi l'IA pour les développeurs ?

GitHub lance le "agent mode" de Copilot

6 février 2025 — GitHub annonce officiellement l'agent mode pour Copilot dans VS Code : l'IA passe d'un simple outil de suggestion à un agent capable de lire une base de code, proposer des corrections, effectuer des tests et itérer seule jusqu'à la fin de la tâche.

📌 Source : GitHub Blog (officiel)

Microsoft lance une application de bureau pour piloter des agents IA

9 juin 2026 — Présentée à Microsoft Build 2026, cette application permet de superviser plusieurs agents IA en parallèle sur différents dépôts : on passe d'un simple assistant à un véritable gestionnaire d'agents autonomes.

📌 Source : Developpez.com

Le "vibe coding" devient le workflow dominant

Février 2026 — Selon l'étude The State of AI in Software Engineering 2025, 63% des organisations déclarent livrer du code plus fréquemment grâce aux IA, avec 8 à 10 outils utilisés en moyenne par équipe. Le développeur devient plus un architecte qui supervise l'IA qu'un simple codeur.

📌 Source : Aujourdhui.ma

Thème 2 — Ce que l'IA apporte concrètement aux développeurs

GitHub Copilot devient gratuit pour tous les développeurs

11 mai 2026 — GitHub ouvre Copilot gratuitement (2000 complétions/mois, 50 messages de chat), sans carte bancaire. Avant, il fallait payer au moins 10$/mois : signe que l'IA de code est devenue incontournable.

📌 Source : Comparer-IA

Copilot passe à une facturation à l'usage

28 avril 2026 — Depuis le 1er juin 2026, Copilot facture au token consommé (GitHub AI Credits) au lieu d'un abonnement à volume illimité — preuve que l'usage professionnel de l'IA de code a explosé au point de ne plus être rentable à prix fixe.

📌 Source : Generation-NT

Microsoft développe ses propres modèles IA de code

29 mai 2026 — À Build 2026, Microsoft annonce des modèles d'IA "maison", dont un modèle spécialisé en génération de code, pour renforcer Copilot face à des concurrents comme Cursor ou Claude Code.

📌 Source : Blog Calipia

Thème 3 — Les limites et les risques de l'IA dans le développement

Plus de 80% du code généré par IA comporterait des failles de sécurité

17 septembre 2025 — Une étude Checkmarx révèle que 60% des entreprises utilisent déjà l'IA pour coder, mais seulement 18% d'entre elles ont mis en place une politique pour encadrer les risques de sécurité liés à ce code.

📌 Source : IT Social

Étude Veracode : le code généré par IA reste peu sécurisé

30 juillet 2025 — Veracode a testé plus de 100 LLM sur 80 tâches de code : 45% des réponses contiennent des vulnérabilités. Java est le langage le plus à risque (plus de 70% d'échec de sécurité).

📌 Source : Veracode / Businesswire

L'ANSSI publie des recommandations sur les risques de l'IA générative

4 février 2026 — L'agence française de cybersécurité note que l'IA générative est de plus en plus utilisée par des attaquants informatiques, mais qu'aucun système n'est encore capable de mener seul une cyberattaque complète. Elle recommande une surveillance continue des systèmes d'IA.

📌 Source : CERT-FR / ANSSI (source officielle)

OWASP Top 10:2025 — référentiel des risques applicatifs web

2025 — Le classement officiel des 10 risques de sécurité les plus critiques pour les applications web (ex : A01 Broken Access Control, A05 Injection). Les failles les plus fréquentes dans le code généré par IA (injection, XSS) correspondent à ces catégories du Top 10 OWASP — un lien direct avec mon cours de cybersécurité.

📌 Source : OWASP Foundation (site officiel)
